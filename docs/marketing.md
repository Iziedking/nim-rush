# NIM RUSH public copy

## One-line pitch

Ride the ridge. Beat your line. Prove the run.

## Short description

NIM RUSH is a daily downhill skill race for Nimiq Mini Apps. Manage speed,
read the surface, clear three mission contracts, and return with a better run.

## What the player feels

The rider owns every decision. A fast entry can become a clean exit, a rough
landing can cost the run, and a safer line can beat a reckless shortcut. The
finish screen makes the reason for the result visible.

## Competition explanation

Practice is open without a wallet. Ranked mode keeps the equipment equal and
uses replay verification for submitted results. Nimiq supports identity and
signed participation; it does not buy speed or decide the score.

## Screenshot captions

- Daily descent: choose the rules and see the three contracts before riding.
- Ridge Run: manage the surface, speed, jump, and obstacle in one line.
- Result ledger: see exactly where the run gained or lost points.
